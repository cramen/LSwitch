LSwitch — экспериментальная alpha-версия
macOS 13+, Apple Silicon и Intel (Universal binary).

Установка
1. Перенесите LSwitch.app в «Программы» (Applications).
2. Запустите приложение. Оно работает в строке меню, без иконки в Dock.
3. Разрешения «Универсальный доступ» и «Мониторинг ввода» выдавайте только
   скачанной вами сборке в настройках macOS по запросу приложения.
4. По умолчанию ручное исправление вызывается двойным Shift. В настройках
   можно выбрать своё сочетание, включая Option+Space, и локальные профили приложений.
   Автопереключение по умолчанию выключено.

Подпись и Gatekeeper
Эта alpha-сборка имеет только техническую ad-hoc подпись. Developer ID и
notarization Apple отсутствуют; macOS может заблокировать запуск.
Мы не снимаем quarantine и не меняем защиту macOS автоматически.
Официальная информация Apple: https://support.apple.com/102445
Если вы не готовы запускать ненотаризованное приложение, дождитесь подписанного релиза.
При обновлении ad-hoc сборки macOS может потребовать повторной выдачи разрешений.

ВАЖНО: ограничения alpha
Приёмка продукта ещё не завершена. Известен риск потери/неверной доставки ввода
при неоднозначном сбое редактирования: change fix-input-recovery остаётся открытым.
Проверяйте приложение на тестовых текстах; не используйте alpha для незаменимых данных.
VS Code пока заблокирован защитным профилем; Terminal/iTerm исключены.
Не все редакторы и режимы поддерживаются. Принудительный clipboard-режим TextEdit
может превысить лимит времени при откате — оставьте встроенный профиль.
Intel-срез собран, но аппаратная приёмка на Intel не выполнена.
