## Why

Этап 0 закрыт по коду и архитектуре (спайки работают, ADR-001 принят), но продуктом LSwitch пока не является: конвертация запускается только вручную из меню, нет хоткеев, переключения раскладки, отката, blacklist и настроек. По TZ.md следующий шаг — MVP (релиз 0.1): ручная конвертация по двойному Shift с откатом и защитой от ложных контекстов.

## What Changes

- **Хоткей конвертации:** двойной Shift конвертирует последнее слово (AX-режим, fallback — clipboard) и переключает системную раскладку следом.
- **Откат:** повторный двойной Shift в течение 3 с возвращает исходный текст и раскладку.
- **LayoutManager:** чтение и переключение системной раскладки через TIS API.
- **AppRules:** blacklist приложений по bundle ID (предустановлены Terminal, iTerm2), редактируемый в настройках.
- **PermGuard:** проверка разрешений Accessibility/Input Monitoring при старте, мониторинг сброса, пункт меню со статусом.
- **Настройки (SwiftUI):** включение/выключение, окно отката, звук при конвертации, blacklist, автозапуск через SMAppService.
- **Конвертер** из спайков становится продуктовым: оркестрация AX → clipboard-fallback, per-app кэш режима, откат.
- Пункты меню «Спайк: …» заменяются продуктовой логикой (спайковый probe-режим `--probe` сохраняется).

## Capabilities

### New Capabilities

- `hotkey-conversion`: ручная конвертация по хоткею (двойной Shift) — детект
  по flagsChanged, оркестрация AX → clipboard-fallback, откат, переключение
  раскладки следом.
- `layout-management`: чтение и переключение системной раскладки.
- `app-rules`: список исключений приложений (blacklist по bundle ID, предустановленные и пользовательские).
- `permissions-guard`: мониторинг разрешений TCC и восстановление после сброса.
- `settings`: окно настроек и их персистентность, автозапуск при входе.

## Impact

- **Код:** новые `LayoutManager`, `HotkeyMonitor`, `Converter`, `AppRules`, `PermGuard`, `SettingsStore` в `LSwitchCore`; переписка `main.swift` (menu bar + SwiftUI Settings); пункты спайков удаляются из меню.
- **Спеки:** основывается на `keyboard-interception` и `text-conversion` из stage0-spikes (MODIFIED), добавляет пять новых.
- **Ограничения:** MVP — только ручная конвертация; автопереключение (классификатор) — этап 2 и сюда не входит.
