## Purpose

LSwitch бесполезен без разрешений Accessibility и Input Monitoring, а macOS
сбрасывает их при обновлениях — пользователь должен узнавать о проблеме
сразу, а не по молчаливому отказу.

## ADDED Requirements

### Requirement: Проверка разрешений при старте

Система SHALL при запуске проверять наличие разрешений Accessibility и
Input Monitoring и MUST при их отсутствии явно уведомить пользователя
с возможностью перейти в Системные настройки.

#### Scenario: Нет разрешений при старте

- **WHEN** приложение запущено без одного из разрешений
- **THEN** показывается уведомление с указанием недостающего разрешения и кнопкой перехода в настройки

### Requirement: Мониторинг сброса разрешений

Система SHALL периодически проверять актуальность разрешений во время работы
и MUST при потере любого из них уведомить пользователя и приостановить
перехват до восстановления.

#### Scenario: Разрешение отозвано во время работы

- **WHEN** пользователь снял разрешение в Системных настройках при работающем приложении
- **THEN** приложение уведомляет о потере и перестаёт перехватывать ввод

#### Scenario: Статус разрешений виден

- **WHEN** пользователь открыл меню приложения
- **THEN** статус обоих разрешений отображается явно
