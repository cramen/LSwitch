## Purpose

Для обработки ввода необходимы Accessibility и Input Monitoring. Пользователь
должен видеть отсутствие или потерю разрешений и понимать, как восстановить
работу; восстановление доступа не должно отменять выбранное им выключение LSwitch.

## ADDED Requirements

### Requirement: Проверка разрешений при старте

Система SHALL при запуске проверять Accessibility и Input Monitoring и MUST
при отсутствии разрешения явно уведомить пользователя с возможностью перейти
в Системные настройки. Наличие одного разрешения не заменяет другое.

#### Scenario: Нет разрешений при старте

- **WHEN** приложение запущено без одного из необходимых разрешений
- **THEN** пользователь видит, какое разрешение отсутствует, и доступный переход к его настройке

### Requirement: Мониторинг сброса разрешений

Система SHALL периодически проверять разрешения во время работы и MUST
при потере любого из них уведомить пользователя и приостановить обработку
до восстановления. Остановка MUST отменять прежний контекст конвертации,
сохраняя уже принятый пользовательский ввод.

#### Scenario: Разрешение отозвано во время работы

- **WHEN** пользователь снял разрешение в Системных настройках при работающем приложении
- **THEN** приложение уведомляет о потере и прекращает обработку до восстановления

#### Scenario: Статус разрешений виден

- **WHEN** пользователь открыл меню приложения
- **THEN** актуальный статус обоих разрешений отображается явно

### Requirement: Восстановление доступа учитывает выключатель

После возврата необходимых разрешений система SHALL возобновлять обработку,
только если пользователь оставил LSwitch включённым. Сохранённое значение OFF
MUST иметь приоритет над автоматическим восстановлением.

#### Scenario: Разрешения вернулись при включённом приложении

- **WHEN** оба разрешения восстановлены, а LSwitch включён
- **THEN** обработка возобновляется без использования старого буфера/контекста undo

#### Scenario: Разрешения вернулись при выключенном приложении

- **WHEN** пользователь выключил LSwitch, затем восстановил разрешения
- **THEN** ввод не обрабатывается до явного включения LSwitch

реализованы; отдельное уведомление/переход при отзыве и реальный цикл отзыва/
