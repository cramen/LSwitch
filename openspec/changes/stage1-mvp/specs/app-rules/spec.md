## Purpose

Список исключений приложений защищает от ложных срабатываний: в терминалах,
IDE и играх автоматическая обработка ввода вредит.

## ADDED Requirements

### Requirement: Blacklist приложений

Система SHALL хранить список bundle ID приложений-исключений и MUST NOT
обрабатывать клавиатуру и конвертировать текст, когда активное приложение
в списке. Предустановленный список MUST включать Terminal.app и iTerm2.

#### Scenario: Активное приложение в blacklist

- **WHEN** фокус в приложении из blacklist и пользователь нажал двойной Shift
- **THEN** конвертация не выполняется, перехваченные события не накапливаются в буфер

#### Scenario: Смена активного приложения

- **WHEN** пользователь переключился из обычного приложения в приложение из blacklist
- **THEN** буфер набранного текста очищается

### Requirement: Редактирование blacklist

Система SHALL позволять добавлять и удалять приложения из списка исключений
в настройках и MUST сохранять список между запусками.

#### Scenario: Добавление приложения

- **WHEN** пользователь добавил bundle ID в настройках
- **THEN** приложение сразу исключается из обработки, запись сохраняется после перезапуска
