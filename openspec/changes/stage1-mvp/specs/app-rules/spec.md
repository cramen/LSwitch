## Purpose

Исключения приложений отключают обработку там, где пользователь не хочет
вмешательства в ввод. Терминалы входят в предустановленные исключения;
остальные приложения, включая IDE, определяются пользовательским списком,
а выбор совместимого механизма замены не означает включение в blacklist.

## ADDED Requirements

### Requirement: Blacklist приложений

Система SHALL хранить предустановленные и пользовательские исключения по
bundle ID и MUST NOT накапливать ввод для конвертации либо менять текст
в активном приложении из списка. Предустановленные исключения MUST включать
Terminal.app и iTerm2.

#### Scenario: Активное приложение в blacklist

- **WHEN** фокус в исключённом приложении и пользователь нажал двойной Shift
- **THEN** конвертация не выполняется, его ввод не накапливается как слово для исправления

#### Scenario: Смена активного приложения

- **WHEN** пользователь переключился из обычного приложения в исключённое
- **THEN** прежний буфер и контекст отката сбрасываются

### Requirement: Редактирование blacklist

Система SHALL позволять добавлять и удалять пользовательские bundle ID
в настройках и MUST сохранять список между запусками. Изменения SHALL
применяться без перезапуска; предустановленные исключения отображаются отдельно.

#### Scenario: Добавление приложения

- **WHEN** пользователь добавил bundle ID в настройках
- **THEN** приложение сразу исключается из обработки, запись сохраняется после перезапуска

#### Scenario: Удаление пользовательского исключения

- **WHEN** пользователь удалил добавленный им bundle ID, не входящий в предустановленные исключения
- **THEN** приложение снова допускается к обычным проверкам безопасности и совместимости

### Requirement: Правила не подменяют проверку фокуса

Допуск приложения по blacklist MUST NOT разрешать преобразование в парольном
поле или при Secure Input. Смена приложения MUST отменять устаревшую операцию,
даже если оба приложения не исключены.

#### Scenario: Парольное поле разрешённого приложения

- **WHEN** фокус находится в password-поле приложения, которого нет в blacklist
- **THEN** ввод не накапливается, Copy/Paste и конвертация не запускаются

#### Scenario: Переход между двумя разрешёнными приложениями

- **WHEN** пользователь сменил приложение во время подготовки операции
- **THEN** отложенная замена не записывает текст в новое приложение

Matching и персистентность проверены unit-тестами. Живой Terminal/iTerm
остаётся в [задаче 5.3](../../tasks.md); password Safari подтверждён отдельно
[протоколом](../../../archive/2026-10-14-fix-conversion-safety/notes.md) и не заменяет проверку blacklist.
