## Purpose

Чтение текущей системной раскладки и её переключение — необходимая часть
конвертации: после исправления текста раскладка должна соответствовать
исправленному тексту.

## ADDED Requirements

### Requirement: Чтение текущей раскладки

Система SHALL определять текущую активную раскладку клавиатуры через TIS API
и MUST сопоставлять её с поддерживаемой парой (русская/английская в MVP).

#### Scenario: Известная раскладка

- **WHEN** активна русская или английская раскладка
- **THEN** система корректно сообщает текущую раскладку

#### Scenario: Неподдерживаемая раскладка

- **WHEN** активна раскладка вне пары ru/en (например, немецкая)
- **THEN** система сообщает «неизвестная раскладка» и не выполняет конвертацию

### Requirement: Переключение раскладки

Система SHALL переключать системную раскладку на противоположную из
поддерживаемой пары через `TISSelectInputSource`.

#### Scenario: Переключение следом за конвертацией

- **WHEN** слово сконвертировано из английской раскладки в русскую
- **THEN** системная раскладка переключается на русскую без действий пользователя
