## Context

См. proposal.md. Из этапов 0–1 уже есть: `KeystrokeBuffer` (разделители,
сброс на control-клавишах), `LayoutMap.invert`, `Converter` с UndoStore
(откат), `LayoutManager`, `AppRules`, настройки. Спеки:
`auto-classification`, `personal-dictionary`. Ограничения TZ.md:
автоконвертация ≤ 200 мс от разделителя, всё офлайн и в памяти, ноль
сетевых запросов в рантайме, точность ≥ 97% и ложные срабатывания ≤ 1%
на тестовом корпусе (задача 2.2).

## Goals / Non-Goals

**Goals:**

- Автоконвертация слова после разделителя при уверенном словарном совпадении.
- Защита от ложных срабатываний (эвристики + обучение на отменах).
- Персональный словарь с редактором в настройках.

**Non-Goals:**

- N-граммный fallback для слов вне словаря (F10 упоминает его; откладываем:
  консервативная стратегия R6 — сначала стабильная точность на словарных
  словах, n-граммы расширяют охват ценой ложных срабатываний).
- Импорт/экспорт словаря исключений (F12 частично — только редактирование;
  экспорт отложен).
- Профили per-app для автоматики (этап 3, F13).

## Decisions

### D1. Словари — Set<String> вместо trie

TZ предполагает trie/DAC для компактности, но нам нужен только точный
lookup слова (префиксные запросы не нужны — нет n-грамм fallback).
Два `Set<String>` по ~50 тыс. слов: ~2–3 МБ в памяти, lookup O(1),
ноль кода сериализации. Словари — текстовые ресурсы (одно слово на строку,
нижний регистр) в `Resources/` таргета LSwitchCore; загрузка лениво при
первом включении автоматики. Это проще и быстрее, чем trie; если размер
станет проблемой — замена локализована в `DictionaryStore`.

Источник: hermitdave/FrequencyWords (OpenSubtitles, CC-BY-SA 4.0) —
ru_50k.txt / en_50k.txt, берётся часть слова (без частот), фильтрация:
только буквы целевого алфавита, длина ≥ 3 (короче всё равно запрещены
эвристикой). Атрибуция — NOTICE + README.

### D2. Скоринг — бинарный, а не вероятностный

TZ описывает скоринг с порогом и гистерезисом. Для консервативного старта
решение бинарное (spec auto-classification): конвертируем iff
`word ∈ dict(другой) && word ∉ dict(текущий)` после отображения в
раскладку другого языка. Т.е. для набранного «ghbdtn» проверяем
`invert("ghbdtn") = "привет" ∈ ru` и `"ghbdtn" ∉ en`. Частоты слов
пока не используются — пороговая настройка по частотам откладывается
до данных бета-тестирования (этап 2, задача 2.4 по TZ).

### D3. Точка интеграции — разделитель в KeystrokeBuffer

В `handleIntercepted` (main.swift): если classifier вернул `.delimiter` и
включена автоматика и слово прошло эвристики — `AutoSwitchCoordinator`
решает и вызывает `Converter.trigger()`-подобный путь. Автоконвертация
идёт через тот же `Converter` (AX → clipboard), откат — тот же UndoStore,
то есть двойной Shift после автоконвертации откатывает её (и это же —
сигнал обучения).

Нюанс: разделитель остаётся в буфере после конвертации —
`KeystrokeBuffer.removeLastWord()` + `removeLastDelimiter()` после
успеха, чтобы следующее слово считалось от чистого места.

### D4. Обучение на отменах — счётчик по словам

`AutoSwitchCoordinator` держит `[String: Int]` отмен (нормализованное
слово в нижнем регистре) + персистентный `PersonalDictionary`
(UserDefaults). На `Converter.Outcome.undone` после автоконвертации
счётчик слова инкрементируется; при достижении 2 — слово уходит в
PersonalDictionary, счётчик сбрасывается. Откат ручной конвертации
обучение НЕ затрагивает (это явное действие пользователя).

### D5. Настройки

`SettingsStore`: + `autoSwitchEnabled` (default false), `undoLearningThreshold`
(в коде константа 2, настройка — этап 3). SwiftUI-окно: секция
«Автопереключение» (тоггл) и «Словарь исключений» (список + удаление +
добавление).

## Risks / Trade-offs

- [Бинарный порог пропустит редкие/опечаточные слова вне словаря] → сознательный консерватизм (R6); охват расширим n-граммами после беты.
- [Словари OpenSubtitles шумные (имена, транслит)] → фильтрация по алфавиту и длине; наблюдаемость через лог; обучение на отменах компенсирует.
- [Автоконвертация через clipboard-режим мигает буфером на глазах у пользователя] → AX-first остаётся приоритетом; для clipboard-приложений автоматика может ощущаться — кандидат в per-app настройки этапа 3.
- [Лицензия CC-BY-SA словарей] → атрибуция в NOTICE/README; словари — данные, не код; при необходимости заменимы (источник изолирован в DictionaryStore).
