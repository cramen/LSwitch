## Purpose

Персональный словарь хранит исходные набранные формы, которые автоматика должна
оставлять без изменений; он пополняется обучением на отменах и редактируется пользователем.

## ADDED Requirements

### Requirement: Хранение и применение словаря исключений

Система SHALL хранить исключения персистентно и MUST исключать эти исходные формы
из автоконвертации без учёта регистра. При добавлении SHALL удаляться крайние
пробелы/переводы строк; пустые значения и дубликаты MUST NOT добавляться.
Исключение действует на набранную форму и не создаёт автоматически исключения
для её преобразования в другую раскладку. Ручной хоткей MUST оставаться доступным
при остальных выполненных условиях конвертации.

#### Scenario: Слово в словаре исключений

- **WHEN** «ghbdtn» добавлено в исключения и пользователь набирает «GHBDTN »
- **THEN** автоконвертация не выполняется независимо от словарного скоринга

#### Scenario: Нормализация и сохранение

- **WHEN** добавлены «  ghbdtn  » и «GHBDTN», затем приложение перезапущено
- **THEN** хранится одно исключение «ghbdtn», которое продолжает действовать

#### Scenario: Пустая запись

- **WHEN** пользователь пытается добавить только пробелы или переводы строк
- **THEN** новая запись не появляется

### Requirement: Редактирование в настройках

Система SHALL показывать список исключений с возможностью добавления и удаления.
Изменения MUST применяться при следующей оценке слова без перезапуска.

#### Scenario: Удаление слова

- **WHEN** пользователь удалил слово из списка в настройках
- **THEN** слово снова участвует в автоконвертации по общим правилам

#### Scenario: Добавление слова

- **WHEN** пользователь добавил исходную форму в исключения
- **THEN** повторный набор этой формы не исправляется автоматически

## Статус подтверждения

Персистентность, отсутствие дубликатов, сравнение без регистра, удаление и применение
исключения покрыты `PersonalDictionaryTests`/`WordClassifierTests`. Общий прогон —
255 тестов без ошибок. В TextEdit подтверждён живой сценарий «две отмены → слово
появилось в уже открытых настройках → следующий набор не исправлен», удаление через UI
и обучение после одной отмены при пороге 1. Настройка порога подключена, задача 3.2 закрыта.
На итоговой сборке ручная кнопка добавления и немедленное действие исключения
подтверждены в Safari; слово затем удалено, исходные настройки восстановлены.
