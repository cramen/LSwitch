## Why

Этап 0 по TZ.md не завершён: инициализация (P0.5) сделана, но три ключевых
архитектурных риска (R1–R3) не закрыты спайками, а ADR-001 (App Sandbox и
способ дистрибуции) открыт. Без ответов на них этап 1 (MVP) строился бы
вслепую: неизвестно, работают ли CGEventTap и AX-конвертация в целевых
приложениях и можно ли сохранить App Sandbox.

## What Changes

- Добавить спайк перехвата клавиатуры: `CGEventTap` в пассивном режиме,
  метка собственных синтезированных событий, автоматическое восстановление
  tap после `kCGEventTapDisabledByTimeout` / `kCGEventTapDisabledByUserInput`.
- Добавить спайк конвертации текста через Accessibility API: чтение и запись
  выделенного текста без буфера обмена, проверка в матрице приложений
  (TextEdit, Safari, Chrome, Telegram, VS Code).
- Добавить спайк clipboard-режима: конвертация через Cmd+C/Cmd+V с полным
  сохранением и восстановлением `NSPasteboard` (все типы данных, проверка
  хэшами pasteboard items).
- Зафиксировать решение по App Sandbox и дистрибуции в ADR-001 по
  результатам спайков.
- Починить запуск unit-тестов локально (xcode-select указывает на Command
  Line Tools без XCTest) и в CI.
- Результаты каждого спайка — воспроизводимый код плюс ручной чек-лист
  верификации (разрешения TCC, sleep/wake, матрица приложений).

## Capabilities

### New Capabilities

- `keyboard-interception`: глобальный перехват событий клавиатуры —
  пассивный режим, различение собственных синтезированных событий,
  восстановление event tap после отключения системой.
- `text-conversion`: конвертация набранного текста между раскладками —
  приоритетный AX-режим без буфера обмена, clipboard-режим с гарантированным
  восстановлением содержимого буфера.

## Impact

- **Код:** новые компоненты в `Sources/LSwitchCore` (event tap, конвертеры),
  точечные изменения в `Sources/LSwitch` для запуска спайков из menu-bar
  каркаса; новые тесты в `Tests/LSwitchCoreTests`.
- **Документы:** `docs/adr/ADR-001-app-sandbox.md` — заполнение решения.
- **Окружение:** настройка xcode-select на полный Xcode (локально), CI.
- **Зависимости:** не добавляются (только системные фреймворки:
  CoreGraphics, ApplicationServices, AppKit).
- **Риски из TZ.md:** закрывает R1 (sandbox), R2 (AX в Electron/SwiftUI),
  R3 (тайминги симуляции нажатий).
