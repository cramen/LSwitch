## Purpose

Конвертация текста, набранного в неправильной раскладке, с гарантией
сохранности буфера обмена: приоритетный режим через Accessibility API
вообще не трогает буфер, резервный clipboard-режим восстанавливает его
содержимое бит-в-бит.

## ADDED Requirements

### Requirement: Конвертация через Accessibility API без буфера обмена

Система SHALL в первую очередь пытаться конвертировать текст через
Accessibility API (чтение и запись `AXSelectedText` / значения поля),
не обращаясь к буферу обмена. Если AX-режим недоступен в текущем
приложении, система MUST автоматически переключаться на clipboard-режим
и запоминать результат выбора режима для этого приложения.

#### Scenario: AX-режим в поддерживаемом приложении

- **WHEN** пользователь запрашивает конвертацию в приложении, поддерживающем запись через AX API
- **THEN** текст конвертируется, а содержимое буфера обмена остаётся нетронутым

#### Scenario: Автоматический fallback

- **WHEN** AX-запись в текущем приложении недоступна или завершается ошибкой
- **THEN** система выполняет конвертацию через clipboard-режим и запоминает выбранный режим для этого приложения

### Requirement: Сохранение буфера обмена в clipboard-режиме

При конвертации через буфер обмена система SHALL сохранять все элементы
`NSPasteboard` всех типов (текст, RTF, изображения, файлы) перед операцией
и MUST восстанавливать их после неё так, чтобы содержимое буфера было
идентично исходному (проверка хэшами pasteboard items). Между шагами
Cmd+C / конвертация / Cmd+V применяются адаптивные паузы с не более чем
3 повторами при детекте неуспеха.

#### Scenario: Буфер идентичен после конвертации

- **WHEN** выполняется конвертация в clipboard-режиме при любом исходном содержимом буфера
- **THEN** после операции хэши всех pasteboard items совпадают с исходными

#### Scenario: Неуспешное чтение буфера

- **WHEN** содержимое буфера после симуляции Cmd+C не соответствует выделенному тексту
- **THEN** система увеличивает паузу и повторяет попытку, но не более 3 раз, после чего отменяет конвертацию и восстанавливает буфер

### Requirement: Отключение в защищённых контекстах

Система MUST NOT перехватывать и конвертировать текст в полях ввода
паролей и других secure-полях (детект через `AXSecureTextField` / флаг
события), а также в приложениях из списка исключений.

#### Scenario: Поле пароля

- **WHEN** фокус находится в secure-поле ввода
- **THEN** перехват и конвертация отключены, набранные символы не попадают в буфер приложения

#### Scenario: Приложение из списка исключений

- **WHEN** активное приложение присутствует в blacklist (по bundle ID)
- **THEN** LSwitch не перехватывает ввод и не выполняет конвертацию
