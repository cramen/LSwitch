## Purpose

Глобальный перехват событий клавиатуры — основа LSwitch: приложение должно
видеть набираемый текст в любом приложении, не мешая вводу и устойчиво
переживая отключения перехвата со стороны системы.

## ADDED Requirements

### Requirement: Пассивный перехват клавиатуры

Система SHALL перехватывать события клавиатуры на уровне сессии через
`CGEventTap` в режиме listen-only: события не модифицируются, не
блокируются и не задерживаются. Обработка одного события в hot path
MUST занимать не более 1 мс; события передаются в отдельную очередь
для дальнейшей обработки без I/O и аллокаций в callback.

#### Scenario: Перехват без влияния на ввод

- **WHEN** пользователь печатает в любом приложении при активном перехвате
- **THEN** все символы доходят до приложения без потерь, искажений и заметных задержек

#### Scenario: Отсутствие разрешений

- **WHEN** у приложения нет разрешения Accessibility / Input Monitoring
- **THEN** система сообщает пользователю о необходимости выдать разрешение и не перехватывает события

### Requirement: Метка собственных синтезированных событий

Система SHALL помечать события, синтезированные самим приложением
(симуляция нажатий при конвертации), уникальным идентификатором источника
и MUST игнорировать их в перехватчике, исключая рекурсию.

#### Scenario: Собственное событие не обрабатывается повторно

- **WHEN** приложение синтезирует нажатия клавиш для вставки сконвертированного текста
- **THEN** перехватчик распознаёт эти события как собственные и не добавляет их в буфер набранного текста

### Requirement: Восстановление event tap после отключения системой

Система SHALL автоматически пересоздавать event tap при получении
`kCGEventTapDisabledByTimeout` или `kCGEventTapDisabledByUserInput` и
MUST сохранять перехват работоспособным через sleep/wake, Fast User
Switching и подключение внешней клавиатуры.

#### Scenario: Отключение по таймауту

- **WHEN** система отключает event tap по таймауту
- **THEN** приложение пересоздаёт tap и перехват продолжается без участия пользователя

#### Scenario: Sleep/wake

- **WHEN** компьютер уходит в сон и просыпается
- **THEN** перехват клавиатуры продолжает работать без перезапуска приложения
