## Purpose

Позволяет выбирать и сохранять удобное сочетание клавиш для безопасного ручного исправления раскладки.

## ADDED Requirements

### Requirement: Сохраняемый ручной хоткей
Система MUST по умолчанию использовать двойной Shift. Пользователь SHALL выбирать двойной Shift либо Ctrl/Command с дополнительными модификаторами и физической клавишей из списка букв, цифр, F1–F12 и пробела. Option+Space SHALL также допускаться без Control/Command. Настройка MUST сохраняться между запусками; отсутствующие или повреждённые данные MUST возвращать двойной Shift.

#### Scenario: Первый запуск
- **WHEN** сохранённого хоткея нет
- **THEN** используется двойной Shift

#### Scenario: Смена и сброс
- **WHEN** пользователь применяет допустимое сочетание или возвращает двойной Shift
- **THEN** настройка сохраняется и действует без перезапуска

### Requirement: Регистрация без потери прежнего хоткея
Обычное сочетание MUST регистрироваться системно до сохранения. При отказе регистрации MUST сохраняться прежний хоткей и показываться ошибка. UI SHALL объяснять, что конфликты с командами отдельных приложений могут не обнаруживаться системой. При OFF или остановке перехвата регистрация MUST освобождаться.

#### Scenario: Сочетание занято
- **WHEN** система отказывает в регистрации нового сочетания
- **THEN** прежняя настройка остаётся действительной, пользователь видит ошибку

### Requirement: Однократная безопасная обработка
Выбранное сочетание MUST вызывать тот же путь ручной конвертации и undo, что двойной Shift, без изменения правил исключённых приложений, Secure Input и прав. Удержание клавиши MUST NOT вызывать повторную конвертацию. Смена хоткея MUST сбрасывать незавершённую последовательность. Собственная синтетика MUST NOT вызывать конвертацию.

#### Scenario: Удержание и повторное нажатие
- **WHEN** клавиша удерживается, затем отпущена и нажата снова
- **THEN** первое нажатие запускает одну операцию, повторное физическое нажатие может запустить следующую

#### Scenario: Исключённое приложение
- **WHEN** хоткей нажат в исключённом приложении
- **THEN** конвертация не запускается

#### Scenario: Option и пробел
- **WHEN** пользователь выбирает только Option и клавишу «Пробел»
- **THEN** сочетание сохраняется и запускает ручное исправление/undo без вставки пробела; обычный пробел остаётся вводом текста
