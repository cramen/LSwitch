## Purpose

Обеспечивает скачиваемую экспериментальную сборку macOS с проверяемым составом и честным описанием ограничений выпуска.

## ADDED Requirements

### Requirement: Проверяемый предварительный дистрибутив
Предварительный выпуск MUST содержать Release-приложение arm64/x86_64 для macOS 13+, ресурсы словарей, лицензионные уведомления, ZIP, DMG и SHA256. Версия приложения и commit исходников MUST быть указаны. Упакованные ресурсы MUST проверяться из извлечённой поставки, не из рабочего checkout.

#### Scenario: Скачивание
- **WHEN** пользователь открывает опубликованный GitHub prerelease
- **THEN** доступны приложение и контрольные суммы, инструкции установки и ограничения

### Requirement: Честные ограничения выпуска
При отсутствии Developer ID/notarization выпуск MUST явно сообщать это и оставаться prerelease. Открытый риск потери ввода при неоднозначном сбое MUST быть описан. Intel binary MUST NOT объявляться проверенным на Intel hardware без такого теста. Release MUST NOT содержать DEBUG probes или личный сертификат разработчика.

#### Scenario: Экспериментальная сборка
- **WHEN** полная продуктовая приёмка ещё не завершена
- **THEN** версия обозначена alpha, открытые этапы не закрываются и обход защиты macOS не выполняется автоматически
