## Purpose

Позволяет пользователю выбирать готовый механизм исправления раскладки для отдельных приложений без новой версии программы.

## ADDED Requirements

### Requirement: Локальное хранение точных профилей
Пользователь MUST иметь возможность выбрать приложение через .app или указать точный bundle ID и сохранить режим: встроенный, только Accessibility, клавиатура+буфер обмена, выключено. Профиль MUST сохраняться между запусками и применяться без перезапуска. Сброс MUST удалять override и возвращать встроенные правила. Неизвестные или повреждённые записи MUST NOT включать небезопасный режим.

#### Scenario: Сохранение и сброс
- **WHEN** пользователь сохраняет локальный профиль, перезапускает приложение и затем сбрасывает профиль
- **THEN** выбор сохраняется после запуска, а сброс возвращает встроенный маршрут

### Requirement: Однозначный выбор маршрута
Accessibility-only MUST NOT переходить к clipboard при unavailable/failed. Клавиатура+clipboard MUST выбирать этот путь до AX-мутации и использовать native selection/commands. Выключенный профиль MUST отказывать до capture/hold/mutation. Встроенный режим MUST сохранять прежнее поведение, включая штатный fallback до мутации.

#### Scenario: Недоступный AX
- **WHEN** выбран Accessibility-only и AX engine недоступен
- **THEN** clipboard не вызывается

#### Scenario: Native clipboard
- **WHEN** выбран клавиатурный clipboard-профиль
- **THEN** используются native selection и Paste с прежними проверками текста, диапазона и clipboard

### Requirement: Ограничения безопасности выше профиля
Локальный профиль MUST NOT отменять терминальные/пользовательские исключения, Secure Input, проверки прав, фокуса, полного текста, диапазона или clipboard. Для приложений с известной непригодностью AX принудительный AX MUST отказывать. Неподтверждённый VS Code MUST сохранять свой защитный запрет. Изменение профиля MUST инвалидировать незавершённую операцию, cached route и предыдущий undo; новый режим SHALL действовать для следующей операции.

#### Scenario: Изменение во время операции
- **WHEN** после захвата контекста профиль изменён
- **THEN** старая операция не получает разрешения на новую мутацию или успешный receipt

#### Scenario: Попытка обойти запрет
- **WHEN** пользователь выбирает AX для известного небезопасного AX-приложения или профиль для исключённого терминала
- **THEN** защитный отказ сохраняется
