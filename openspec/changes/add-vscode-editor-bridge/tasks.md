## Текущий допуск к работе

**BLOCKED: путь `TextEditor.edit` установленного VS Code 1.134.0 не проходит G3.**
Точные metadata, SHA-256, UTF-8 byte offsets и статический контрпример сохранены в
[design](design.md#точная-цепочка-и-контрпример-g3). Это отрицательный feasibility
результат конкретного пути, не feature PASS и не доказательство невозможности
всех будущих bridge. G1–G4 и hold ≤400 мс остаются прежними; D13 сохраняется.

До нового доказанного контракта получателя и актуализации этих артефактов задачи
разделов 2–7 **не выполняются**: нет реализации transport/extension/VSIX, установки,
пробных production submissions или обхода через keybinding. Следующий допустимый
шаг — read-only поиск/проверка receiver-side cancel/commit fence либо истечения
запроса в точке применения, совместимых с G3; затем завершение остальных gates.
