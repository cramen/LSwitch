# LSwitch

Нативное macOS-приложение для исправления текста, набранного в неправильной
раскладке клавиатуры (`ghbdtn` → `привет`). Открытая и современная замена
Punto Switcher для Mac.

**Статус:** этап 2 — автопереключение (словарный классификатор) реализовано, идёт ручная приёмка. MVP проверен на живой системе (двойной Shift → конвертация → переключение раскладки). Этап 0 завершён, ADR-001 принят: дистрибуция вне Mac App Store (Developer ID + notarization).

## Принципы

- 🍎 Нативный Swift, universal binary (Apple Silicon + Intel), macOS 13+
- 🔒 Ноль телеметрии и сетевых запросов, набранный текст не покидает память процесса
- 📋 Буфер обмена не затирается (AX-режим либо полный restore)
- 🎯 Per-app профили и защита от ложных срабатываний
- 📖 Открытый код (MIT)

Техническое задание и план: [TZ.md](TZ.md)

## Сборка и запуск

```bash
swift build            # сборка
swift test             # unit-тесты
swift run lswitch      # запуск menu-bar агента (каркас)
```
