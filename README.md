# LSwitch

Нативное macOS-приложение для исправления текста, набранного в неправильной
раскладке клавиатуры (`ghbdtn` → `привет`). Открытая замена Punto Switcher для Mac.

**Статус на 2026-10-15:** ручная конвертация и словарная автоматика реализованы,
но **приёмка этапов 0, 1 и 2 ещё не завершена**. Исправления сохранности текста,
точного undo и защищённых полей приняты в своём объёме и
[архивированы](openspec/changes/archive/2026-10-14-fix-conversion-safety/notes.md).
Это не закрывает полную матрицу совместимости или подготовку релиза.

Последний общий локальный `make test` (2026-10-15): **255 тестов, 0 ошибок, 0 пропусков**.
Новые проверки включают реальную доставку маркированного и внешнего keyUp через tap,
валидные RTF/PNG и файловые URL в частном pasteboard, отказ переключения TIS,
разрешения и настройки. [CI кода `8a23a8a`](https://github.com/cramen/LSwitch/actions/runs/38639305713)
также прошёл: build, 255 тестов без ошибок/пропусков и SwiftLint strict без нарушений.

## Что проверено и что остаётся

- В отдельных тестовых документах TextEdit, Safari, Obsidian и GIGA IDE
  проверены перечисленные в архивном протоколе конвертации ru/en, продолжение
  ввода, точный undo и отсутствие потери слова. Не каждый сценарий проверен
  во всех четырёх приложениях. Первые быстрые сценарии Obsidian и Safari после
  запуска могут безопасно отказаться от исправления, сохранив введённый текст.
  Прогретые Safari textarea/contenteditable и password-поле повторно проверены
  на итоговой сборке; безопасный отказ не считается успешным исправлением.
- На живой системе проверены окно настроек, OFF → ON, отзыв/возврат Accessibility
  и сохранение общего OFF при возврате разрешения. Проверены обычная регистрация
  и снятие Login Item, изменение/истечение окна undo при 1/3 с, обучение после
  двух отмен и после одной при пороге 1, обновление открытого списка и ручные add/remove.
  [Протокол MVP](openspec/changes/stage1-mvp/notes.md),
  [протокол автоматики](openspec/changes/stage2-autoswitch/notes.md).
- Остаются независимый отзыв/возврат Input Monitoring, реальные pending/error
  Login Item и запуск после входа, звук ON/OFF и живые Terminal/iTerm.
  Обучение не устраняет известные ложные исправления в кодовом контексте.
- Открыты восьмичасовой прогон с физической клавиатурой, sleep/wake, смена
  сессии и переподключение устройства. Задержка ≤200 мс ещё не подтверждена
  отдельными измерениями; 400 мс допуска к мутации не являются такой метрикой.
- Chrome не входил в подтверждённый живой прогон. Исходная AX-матрица ≥3 из 5
  приложений, clipboard-матрица TextEdit/Chrome и отдельный клавиатурный
  Cmd+C/V в RU/EN остаются открытыми: успех нативного меню не доказывает этот транспорт.
- Unit round-trip файловых URL не является проверкой всех реальных clipboard
  providers. Ленивое чтение, file promises и приём восстановленных данных
  разными приложениями остаются в живой матрице.

Точные статусы: [этап 0](openspec/changes/stage0-spikes/tasks.md),
[этап 1](openspec/changes/stage1-mvp/tasks.md),
[этап 2](openspec/changes/stage2-autoswitch/tasks.md).

## Качество классификатора

Новый размеченный корпус содержит **141 запись и 1029 токенов**:
101 предложение RU/EN, 20 смешанных предложений и 20 строк кода.

| Набор | Accuracy | Ложные срабатывания среди корректных токенов |
|---|---:|---:|
| Весь корпус | 99,51% (1024/1029) | 0,21% (2/939) |
| Поднабор кода | 97,65% (83/85) | 2,35% (2/85) |

Recall ошибочной раскладки — 96,67% (87/90). Общий порог FP ≤1% выполнен
на этом наборе, но в коде он превышен. Это не оценка ошибок за рабочий день
и не результат на 1000 предложениях. Автоматика **по умолчанию выключена**.
[Методика, состав и несовпадения](openspec/changes/stage2-autoswitch/notes.md).

## Принципы

- 🍎 Swift, AppKit/SwiftUI, macOS 13+; живая проверка выполнена на Apple Silicon.
  Universal binary для Apple Silicon и Intel остаётся требованием релизной поставки.
- 🔒 Без телеметрии и сетевых запросов; история нажатий не записывается на диск.
- 📋 AX-путь не меняет clipboard; clipboard-путь восстанавливает собственный
  снимок, сохраняя более новое копирование пользователя. Границы providers указаны выше.
- 🎯 Встроенные профили совместимости Safari/Electron и исключения приложений;
  пользовательские per-app настройки автоматики/хоткеев ещё в дорожной карте.
- 📖 Открытый код (MIT); словари — OpenSubtitles CC-BY-SA (см. [NOTICE.md](NOTICE.md)).
- 🛠 Работа через OpenSpec: активные изменения — `openspec/changes/`,
  архивированные изменения — `openspec/changes/archive/`, опубликованные требования — `openspec/specs/`.

Техническое задание и план: [TZ.md](TZ.md).

## Сборка и запуск

```bash
make build      # сборка через полный Xcode; xcode-select остаётся на CLT
make test       # unit- и доступные интеграционные тесты
make app        # .app-бандл со стабильной dev-подписью (.build/LSwitch.app)
make run-app    # сборка + запуск menu-bar агента
```

Для работы нужны Accessibility и Input Monitoring. Подробнее про подпись,
TCC и диагностику (`lswitch --probe`, логи): [docs/dev-setup.md](docs/dev-setup.md),
особенности macOS API: [docs/macos-quirks.md](docs/macos-quirks.md).
Принят [ADR-001](docs/adr/ADR-001-app-sandbox.md): без App Sandbox, вне Mac App Store.
Текущая подпись «LSwitch Dev» обеспечивает локальную разработку;
Developer ID, notarization и релизный дистрибутив ещё не приняты.
